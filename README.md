# ✈️ Classification and Captioning of Aircraft Damage Using Machine Learning

## Overview

This project automatically classifies aircraft damage and generates descriptive captions using Deep Learning and Natural Language Processing.

The system uses VGG16 Transfer Learning for image classification and BLIP Transformer for image caption generation.

---

## Features

- Aircraft Damage Classification
- Automatic Caption Generation
- VGG16 Transfer Learning
- BLIP Transformer
- Streamlit Web Interface
- Automated Inspection Reports
